# minecraft-srv

The fresh world and migrated inventories are included in this repository. `server.properties` selects `world_fresh_20260906`; the original `world` remains available for rollback.

Use Java 21 and start with `sh run.sh nogui` on Linux or `run.bat` on Windows. See [WORLD_RESET.md](WORLD_RESET.md) for deployment, inventory transfer, grave recovery, and rollback details.
